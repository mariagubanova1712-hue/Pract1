# Pract1

## Этап 1. REPL

Цель: создать минимальный прототип. Большинство функций в нем пока представляют собой заглушки, но диалог с пользователем уже поддерживается.
Что сделано:
- приложение с графическим интерфейсом (tkinter), в заголовке окна — имя VFS;
- простой парсер: введённая строка разбивается по пробелам на команду и аргументы;
- команды ls и cd — заглушки, выводят своё имя и аргументы;
- команда exit закрывает приложение;
- при вводе неизвестной команды выводится ошибка «команда не найдена».

Запуск: `python3 emulator.py`
