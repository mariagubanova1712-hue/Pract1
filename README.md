# Эмулятор командной оболочки UNIX (вариант 8)

Эмулятор языка оболочки ОС с графическим интерфейсом на Python (tkinter).
Работа эмулятора максимально похожа на командную строку UNIX-подобной ОС.

## Структура

- `src/emulator.py` — исходный код эмулятора;
- `tests/` — тесты;
- `run.sh`, `run.bat` — скрипты запуска.

## Функции и команды

- `parse(line)` — разбивает строку по пробелам на команду и аргументы;
- `Shell.execute(line)` — выполняет команду и возвращает её вывод;
- `App` — окно эмулятора, в заголовке отображается имя VFS.

| Команда | Описание |
|---------|----------|
| `ls`    | заглушка: выводит имя и аргументы |
| `cd`    | заглушка: выводит имя и аргументы |
| `exit`  | закрывает эмулятор |

Неизвестная команда выводит ошибку `<команда>: команда не найдена`.

## Запуск и тесты

Требуется Python 3.

```
run.bat                                   # Windows
./run.sh                                  # Linux / macOS
python -m unittest discover -s tests      # тесты
```

## Пример использования

```
$ ls -l /home
ls ['-l', '/home']
$ cd docs
cd ['docs']
$ hello
hello: команда не найдена
$ exit
```
